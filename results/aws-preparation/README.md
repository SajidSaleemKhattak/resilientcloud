# AWS preparation evidence — no deployment

Prepared on 2026-11-04 for the user-confirmed Free plan ($100 credits, 182 days remaining). No AWS account authentication, provisioning, registry push, DNS change or deployment was performed.

- `pricing-fetch.json`, `aws-price-rows.csv`: unauthenticated public AWS us-east-1 price-list retrieval and retained matching rows. The raw extract includes other terms; only the three explicitly filtered OnDemand/Linux/shared/Used and gp3 rows in `selected-prices.json` are used by the estimate.
- `cost-estimate.json`: computed compute/EBS/public-IPv4 credit use, assumptions and schedules. Generated by `node tools/aws-cost.mjs`; `cost-tests.log` contains three passing calculation tests. No T4g promotional discount is assumed.
- `profile/report.json`, `profile/traffic.jsonl` and adjacent journals/logs: a new short local sizing/HTTPS check, not a rerun of the completed experiment matrix. Five Docker samples each for idle/load, roughly 30–36 seconds per phase; 350 successful HTTPS requests and no skips. Maximum observed aggregate container memory 277.31 MiB; configured caps 832 MiB. Host OS/daemon memory and EC2 performance were not measured.
- `profile/test-public-root.crt`: **public certificate only** for explicitly trusted, local-only TLS validation. The private CA key was never copied. No public-domain ACME certificate was requested during this check.
- `configuration-checks.json`: merged AWS configuration validated with fault injection false/true; public ingress/private networks, socket isolation, disabled restart policies, no on-instance builds/pulls and unchanged detection settings checked.
- `caddy-validation.log`: production Caddyfile validated offline, with the same capability boundary as Compose. `caddy-validation-attempt-1.txt` preserves the earlier command's missing NET_BIND_SERVICE capability error; the production overlay already had that capability, so no deployed isolation was relaxed.
- `bundle-validation.json`, `package-console.log`: locally prepared content-pinned ARM64 bundle, checksum checks and local image save/load identity verification. Image archives themselves remain under `.cache/aws-bundle-*/`, excluded from Git.
- `tests.log`: all 60 backend/controller/tool tests passed after adding the cost tests. All milestone-1/2/3 evidence, core application and original local Compose files were verified unchanged against checkpoint `7eecc34`.

The public HTTPS issuance path, real EC2 memory/CPU/EBS behavior, account-specific capacity/quotas, Ubuntu bootstrap and authenticated host maintenance remain future remote checks. Shell scripts have local syntax checks; the archive script is not claimed to have been executed against EC2. See `docs/AWS.md` for exact operator steps, credit guardrails, missing inputs and the single-host limitation.
